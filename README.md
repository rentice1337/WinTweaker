# WinTweaker — настройка Windows 10

Программа на C# (WinForms, .NET 8) для тонкой настройки Windows 10.

## Возможности
**Чего нет у других твикеров**
- **Сторож настроек** — после крупных обновлений Windows часто откатывает твики. WinTweaker замечает это (в окне и заданием при входе в систему) и возвращает одной кнопкой.
- **Оценка системы 0–100** и советы под ваше железо: SSD/HDD, ноутбук/ПК, поддержка HAGS видеокартой, объём ОЗУ, место на диске, автозагрузка.
- **«Что меняется»** у каждой настройки: точные ключи реестра и команды — до применения.
- **Точный откат** любого сеанса из «Истории»: реестр побайтно, службы — к прежнему типу запуска, DNS и схема питания — к прежним значениям.
- **Диагностика**: время загрузки Windows «до/после» WinTweaker, BSOD и аварийные выключения с объяснением по-русски, тест скорости DNS.
- **Палитра команд Ctrl+K** — найти и переключить любую из ~120 настроек с клавиатуры.
- **Профиль кодом** — строка `WT1-…`: скинул другу, он вставил и получил те же настройки.

**Остальное**
- 13 разделов: конфиденциальность, интерфейс, проводник, производительность, безопасность, приложения, автозагрузка, службы, обновления, игры, обслуживание, сеть, обход блокировок.
- Пресеты: Рекомендуемый, Игровой, Приватность, Слабый ПК.
- Интерфейс «неон и стекло»: размытые обои под окном (как Mica), подсветка карточек под курсором, 5 цветов акцента, анимации. Если в Windows выключены анимации или прозрачность — программа это уважает.
- Точка восстановления перед применением.

**Горячие клавиши:** Ctrl+K — палитра, Ctrl+Enter — применить, F5 — перепроверить.

## Скачать
Готовый `WinTweaker.exe` — на странице **Releases** репозитория. Один файл, .NET ставить не нужно.
Запускается от администратора (нужно для изменения системных параметров).

## Сборка
- **Через GitHub (без установки .NET):** каждый пуш в `main` собирается в Actions — готовый exe лежит в артефактах сборки.
- **Релиз:** `git tag v1.0.0` → `git push origin v1.0.0` — Actions соберёт exe, посчитает SHA-256 и опубликует релиз с описанием изменений.
- **Локально:** установите [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и запустите `build.bat` — exe появится в папке `publish`.

## Первая публикация на GitHub
1. Создайте пустой репозиторий на github.com (без README и лицензии — они уже есть).
2. В папке проекта:
   ```
   git init
   git add .
   git commit -m "WinTweaker 1.0.0"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/WinTweaker.git
   git push -u origin main
   git tag v1.0.0
   git push origin v1.0.0
   ```
3. Через пару минут релиз с exe появится во вкладке **Releases**.

## Как добавить свою настройку
Откройте `Catalog.cs` и допишите строку в нужной категории:
```csharp
t.Add(R("Интерфейс", "Название", "Описание",
    @"HKCU\путь\к\разделу", "ИмяПараметра", значениеВкл, значениеВыкл));
```
- `R` — один параметр реестра, `M` — несколько сразу, `S` — отключение службы, `A` — удаление UWP-приложения.
- `null` вместо значения «выкл» — параметр удаляется (возврат к умолчанию).
- Для сложных случаев создайте `new Tweak { IsApplied = ..., Apply = ..., Revert = ... }`.

## Структура
- `Core.cs` — модель `Tweak`, работа с реестром и командами.
- `Catalog.cs` — все настройки.
- `MainForm.cs` — окно и логика.
- `UI.cs` — тема и собственные контролы (переключатели, карточки, меню).
- `RussiaNetwork.cs` — раздел «Обход блокировок».
- `Glass.cs` — стеклянный фон, прожектор, прокрутка без полос.
- `Palette.cs` — палитра команд.
- `Watch.cs` — сторож настроек.
- `Advisor.cs` — индекс и рекомендации.
- `Diagnostics.cs` — загрузка, сбои, тест DNS.
- `Journal.cs` — журнал изменений и откат.
- `Startup.cs` — менеджер автозагрузки.
- `Dashboard.cs` — главная страница и сведения о системе (реестр + WinAPI).
- `Dialogs.cs` — диалоги, тосты, выбор акцента, настройки программы.
- Анимации: класс `Motion` в `UI.cs` (expo-out, твины на общем таймере).
