# WinTweaker — настройка Windows 10

Программа на C# (WinForms, .NET 8) для тонкой настройки Windows 10 и игр.

## Как устроено окно
- **6 разделов** слева: Главная, Игры, Система, Программы, Сеть, Инструменты; «Настройки» — внизу. Внутри раздела — вкладки.
- Отмечаете нужное переключателями — внизу появляется панель «Отмечено N изменений». Ничего не меняется до кнопки **«Применить»**, перед применением видно каждое изменение, а откатить можно в «Истории».
- У каждой настройки — короткое объяснение и метки: «безопасно», «нужна перезагрузка», «для опытных», «разовое действие».
- При первом запуске — выбор работы в трее и автозапуска, затем короткий тур.

## Возможности
**Чего нет у других твикеров**
- **Сторож настроек** — после крупных обновлений Windows часто откатывает твики. WinTweaker замечает это (в окне и заданием при входе в систему) и возвращает одной кнопкой.
- **Оценка системы 0–100** и советы под ваше железо: SSD/HDD, ноутбук/ПК, поддержка HAGS видеокартой, объём ОЗУ, место на диске, автозагрузка.
- **«Что меняется»** у каждой настройки: точные ключи реестра и команды — до применения.
- **Точный откат** любого сеанса из «Истории»: реестр побайтно, службы — к прежнему типу запуска, DNS и схема питания — к прежним значениям.
- **Диагностика**: время загрузки Windows «до/после» WinTweaker, BSOD и аварийные выключения с объяснением по-русски, тест скорости DNS.
- **Палитра команд Ctrl+K** — найти и переключить любую из ~120 настроек с клавиатуры.
- **Профиль кодом** — строка `WT1-…`: скинул другу, он вставил и получил те же настройки.

**Игровой центр**
- **Мои игры** — находит игры в Steam, Epic Games, EA app, Battle.net, Riot и BSG (или добавьте exe вручную), с обложками.
- **Пресеты** для CS2, Apex Legends, Hunt: Showdown 1896, Escape from Tarkov, VALORANT, Fortnite, Dota 2, PUBG, Rainbow Six Siege, Call of Duty, Overwatch 2, Rust, THE FINALS, Deadlock, Marvel Rivals, League of Legends, «Мира танков», GTA V — и общий для любой игры:
  высокий приоритет процессора, мощная видеокарта, отключение оптимизации во весь экран и QoS-приоритет трафика для exe игры, системные настройки и советы по настройкам в самой игре. Файлы игры не трогаются.
- **Игровой режим «Не беспокоить»** — сам включается при запуске игры: без уведомлений и анимаций, пауза загрузки обновлений, «Высокая производительность», по желанию закрывает торренты/облака и выключает фоновый поиск Wi-Fi. После игры всё возвращается (даже после сбоя).
- **Монитор соединения** — во время игры раз в секунду пинг до роутера и до интернета, после матча — отчёт с графиком: где были скачки, дома или у провайдера.
- **Пинг до серверов** — регионы Valve (CS2, Dota 2, Deadlock), AWS (Fortnite) или свой адрес; **трассировка** с задержкой на каждом узле.
- **Готовность к игре** — светофор: питание, Game DVR, фоновая нагрузка, память, загрузки, пинг, обновления, драйвер видеокарты.
- **Видеодрайвер**: быстрый сброс (Win+Ctrl+Shift+B) и перезапуск видеокарты; **кэш шейдеров** NVIDIA/AMD/Intel/DirectX/Steam.

**Круговой пульт в трее** (клик по значку или своя горячая клавиша, по умолчанию Ctrl+Alt+W)
- 8 секторов вокруг курсора — набор и порядок настраиваются (19 действий), место открытия, подсказка и число игр — тоже.
- «Игры» раскрывают второе кольцо с обложками — запуск в один клик.
- Начни печатать — кольцо становится палитрой: команды, разделы, игры и любая из настроек (понимает и неправильную раскладку).
- Под кольцом — одна главная подсказка «прямо сейчас», в центре — живые ОЗУ/CPU и результаты действий.
- На значке — логотип с точкой состояния: всё в порядке, есть совет, проблема или идёт игровой режим.

**Игровой оверлей** (Ctrl+Shift+O или сам при запуске игры)
- FPS, время кадра с графиком, 1% low — через события Windows (ETW), без внедрения в игру (DirectX 9–12); CPU, загрузка и температура GPU, пинг и потери, ОЗУ, часы, время в игре.
- Три стиля: неоновая капсула, тактический HUD и панель-дашборд. Любой угол или своё место (перетащить мышью), прозрачность фона.
- Линия цели FPS (частота монитора), предупреждения цветом, тихий режим — оверлей еле виден, пока всё хорошо.
- FPS за игру (средний, 1% low, график) попадает в отчёт после матча.

**Ещё**
- Игровая статистика: часы в каждой игре, средний FPS и пинг, график по дням.
- Частота мониторов: находит 60 Гц вместо 144/165/240 и включает максимум в один клик.
- Тест мыши: реальная частота опроса и её стабильность (Raw Input).
- Диагностика: «Куда делось место» (самые большие папки с переходом внутрь) и здоровье дисков (SMART: ресурс SSD, температура, ошибки).
- Игры из EA app находятся по списку установок самого EA app.

**Остальное**
- **Не только вкл/выкл:** варианты и ползунки — расположение панели задач, скорость мыши и колеса, повтор клавиш, смена раскладки, таймауты дисплея и сна, отсрочка обновлений, активные часы.
- **Контекстное меню:** добавить «Копировать путь», «Открыть PowerShell/командную строку здесь», «Стать владельцем», «Копировать/Переместить в папку…»; убрать «Поделиться», «Отправить на устройство», «Восстановить прежнюю версию» и др.
- **Программы:** 34 популярные программы — отметил и поставил через winget.
- **Свои наборы:** сохраните текущие отметки под именем и включайте одним кликом.
- Пресеты: Рекомендуемый, Игровой, Приватность, Слабый ПК.
- Интерфейс «неон и стекло»: размытые обои под окном (как Mica), подсветка карточек под курсором, 5 цветов акцента, анимации. Если в Windows выключены анимации или прозрачность — программа это уважает.
- Точка восстановления перед применением.

**Горячие клавиши:** Ctrl+K — палитра, Ctrl+Enter — применить, F5 — перепроверить.

## Скачать
Готовый `WinTweaker.exe` — на странице **Releases** репозитория. Один файл, .NET ставить не нужно.
Работает только от администратора: системные параметры, службы и счётчик FPS без этого недоступны. Если запустить без прав, программа сама попросит их через запрос Windows. Игры из пульта запускаются с обычными правами — так, как ждут лаунчеры и античиты.

### Предупреждение «Неизвестный издатель»
У exe нет платной цифровой подписи, поэтому Windows спрашивает подтверждение при первом запуске скачанного файла.
- Окно «Не удаётся проверить издателя» → снимите галочку «Всегда спрашивать» → **Запустить**.
- Синее окно SmartScreen → **Подробнее** → **Выполнить в любом случае**.
- Или один раз: правый клик по файлу → **Свойства** → **Разблокировать** → ОК. После этого вопросов не будет.

Проверить подлинность: `certutil -hashfile WinTweaker.exe SHA256` и сравнить с файлом `.sha256` из релиза.

## Сборка
- **Через GitHub (без установки .NET):** каждый пуш в `main` собирается в Actions — готовый exe лежит в артефактах сборки.
- **Релиз:** `git tag v1.0.0` → `git push origin v1.0.0` — Actions соберёт exe, посчитает SHA-256 и опубликует релиз с описанием изменений.
- **Локально:** установите [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и запустите `build.bat` — exe появится в папке `publish`.

## Первая публикация на GitHub
1. Создайте пустой репозиторий на github.com (без README и лицензии — они уже есть).
2. В папке проекта:
   ```
   git init
   git add .
   git commit -m "WinTweaker 1.0.0"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/WinTweaker.git
   git push -u origin main
   git tag v1.0.0
   git push origin v1.0.0
   ```
3. Через пару минут релиз с exe появится во вкладке **Releases**.

## Как добавить свою настройку
Откройте `Catalog.cs` и допишите строку в нужной категории:
```csharp
t.Add(R("Интерфейс", "Название", "Описание",
    @"HKCU\путь\к\разделу", "ИмяПараметра", значениеВкл, значениеВыкл));
```
- `R` — один параметр реестра, `M` — несколько сразу, `S` — отключение службы, `A` — удаление UWP-приложения.
- `null` вместо значения «выкл» — параметр удаляется (возврат к умолчанию).
- Для сложных случаев создайте `new Tweak { IsApplied = ..., Apply = ..., Revert = ... }`.

## Структура
- `Core.cs` — модель `Tweak`, работа с реестром и командами.
- `Catalog.cs` — все настройки.
- `MainForm.cs` — окно и логика.
- `UI.cs` — тема и собственные контролы (переключатели, карточки, меню).
- `RussiaNetwork.cs` — раздел «Обход блокировок».
- `Glass.cs` — стеклянный фон, прожектор, прокрутка без полос.
- `Palette.cs` — палитра команд.
- `Watch.cs` — сторож настроек.
- `Advisor.cs` — индекс и рекомендации.
- `Diagnostics.cs` — загрузка, сбои, тест DNS.
- `Journal.cs` — журнал изменений и откат.
- `Startup.cs` — менеджер автозагрузки.
- `Dashboard.cs` — главная страница и сведения о системе (реестр + WinAPI).
- `Dialogs.cs` — диалоги, тосты, выбор акцента, настройки программы.
- `GameData.cs` — пресеты игр; `GameLibrary.cs` — поиск игр и обложки; `GameExe.cs` — настройки Windows для exe игры.
- `GameMode.cs` — игровой режим, слежение за запуском игр, фоновые программы, сброс видеодрайвера, кэш шейдеров, проверка готовности.
- `GameNet.cs` — пинг до регионов, трассировка, монитор соединения; `GameWidgets.cs`, `GamesPage.cs` — страница «Игровой центр».
- `Tray.cs` — значок в трее, подсказки «сейчас», горячая клавиша; `Wheel.cs` — круговой пульт; `Sampler.cs` — сборщик показателей в фоне.
- Анимации: класс `Motion` в `UI.cs` (expo-out, твины на общем таймере).
